# Shanghai Example

## 用户输入

```text
做一个上海版，机场、港口和黄浦江要明显。
```

## 推荐模式

`Infrastructure + Cinematic`

## 提示词

```text
生成一张上海立体微缩地图沙盘。底层是一张暖米黄色复古长三角纸质地图，具有旧式印刷道路、河网、行政边界与纸张纤维。上海区域从二维地图中立体生长，黄浦江成为城市构图主轴。

清晰表现外滩历史建筑群、陆家嘴天际线、东方明珠、上海中心大厦、环球金融中心与金茂大厦。强化浦东国际机场与虹桥机场：表现真实跑道、航站楼、机坪、塔台和少量飞机。港口方向表现码头、泊位、船只和港区道路，使机场、港口与城市水网形成完整基础设施系统。

地图中心标记“Shanghai 上海”，并少量标注 Huangpu River 黄浦江、Pudong 浦东、Hongqiao 虹桥、Yangtze Estuary 长江口。35–45 度斜俯视，移轴微距摄影，暖色自然光，真实水面反射，博物馆级城市沙盘，复古纸图与现代城市形成对比。
```

## 重点检查

- 黄浦江必须成为城市结构主轴。
- 外滩与陆家嘴隔江对应。
- 两座机场不能合并为一个。
- 港口必须与真实水体连接。

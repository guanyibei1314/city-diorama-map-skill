# Xiamen Example

## 用户输入

```text
做一个厦门的立体纸上地图，要体现鼓浪屿、厦门大学、南普陀寺、双子塔、高崎机场、翔安机场、港口和跨海桥。
```

## 推荐模式

`Infrastructure + Cinematic`

## 完整提示词

```text
生成一张极其精致的厦门立体微缩地图沙盘。底层是一张暖米黄色复古中国东南沿海纸质地图，带真实纸张纹理、旧式印刷道路、海岸线、地名、比例尺和指南针。厦门区域从二维地图中立体生长出来，形成博物馆级 3D 城市微缩模型。

主视觉清晰表现鼓浪屿、厦门大学、南普陀寺、世茂海峡双子塔、集美学村、演武大桥，并突出厦门岛、海湾、沙滩、港口和跨海桥梁的滨海岛城特征。北部合理位置表现高崎机场：跑道、滑行道、航站楼、机坪、塔台和少量飞机；东北/翔安方向表现翔安机场：更大的现代机场布局、跑道、航站楼、机坪和飞机。两个机场都应与道路、海岸和城市结构自然连接，而不是孤立悬浮。

前景放置鼓浪屿及渡轮航迹，中景为厦门岛主城区、厦大、南普陀与双子塔，后景延伸至集美、高崎机场、翔安机场与福建东南沿海。地图上以暗红色星标标记“Xiamen 厦门”，并少量标注“Gulangyu 鼓浪屿”“Jimei 集美”“Gaoqi Airport 高崎机场”“Xiang'an Airport 翔安机场”“Zhangzhou 漳州”“Quanzhou 泉州”“Taiwan Strait 台湾海峡”。

采用 35–45 度斜俯视，tilt-shift macro photography，主体清晰，前后景自然虚化，暖金色自然光从左上方照射，水面有克制高光和船迹。真实纸张、建筑、植被和水体材质，PBR materials, global illumination, photorealistic miniature city diorama, vintage cartographic map, 3D topographic relief map, museum-quality architectural scale model, ultra detailed, cinematic natural lighting。
```

## 重点检查

- 高崎机场与翔安机场要同时存在，且位置不能混淆。
- 鼓浪屿应表现为小岛 + 历史建筑 + 密集绿植，而不是普通住宅区。
- 双子塔应靠近海岸，并作为现代天际线识别点。
- 厦门大学与南普陀寺空间关系应接近真实。
- 演武大桥必须真正跨海/贴海连接，而不是悬空装饰。

# Chongqing Example

## 用户输入

```text
做一个重庆版，重点体现山城、长江、嘉陵江和跨江桥。
```

## 推荐模式

`Tourism + Cinematic`

## 提示词

```text
生成一张重庆立体微缩地图沙盘。底层是一张暖米黄色复古西南纸质地图，重庆主城区从二维地图中显著向上生长，形成强烈起伏的山地城市地形。长江与嘉陵江穿过城市并在核心区域汇合，河谷、陡坡、山脊、道路和建筑依地形层叠分布。

清晰表现朝天门、来福士、解放碑核心区、洪崖洞、跨江大桥与山城立体道路。桥梁必须真正跨越长江或嘉陵江，道路应沿山体高差盘旋，强调重庆独特的垂直城市结构。

地图主标签为“Chongqing 重庆”，周边少量标注 Yangtze River 长江、Jialing River 嘉陵江、Chaotianmen 朝天门。采用 35–45 度斜俯视、移轴微距摄影、暖色自然光和浅景深，突出博物馆级山地城市微缩模型质感。
```

## 重点检查

- 山地起伏必须明显，不能做成平原城市。
- 两江关系和汇合位置要成为构图核心。
- 桥梁、道路和建筑必须体现高差。

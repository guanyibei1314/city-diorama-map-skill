# Beijing Example

## 用户输入

```text
做一个北京版，突出故宫、天坛、鸟巢、央视大楼、中国尊和燕山。
```

## 推荐模式

`Tourism + Cinematic`

## 提示词

```text
生成一张北京立体微缩地图沙盘。底层为暖米黄色复古华北纸质地图，北京区域从二维地图中立体生长，形成精致的 3D 地形与城市模型。核心地标包括故宫、天坛、国家体育场鸟巢、央视总部大楼、中国尊与 CBD 天际线。西北方向燕山山脉从纸面明显隆起，山谷、道路和植被具有真实地形层次。

主视觉以故宫为古城核心，现代 CBD 与体育建筑在后方形成时代对比。以暗红色星标标记“Beijing 北京”，周边少量标注 Tianjin 天津、Hebei 河北、Yan Mountains 燕山等。35–45 度斜俯视，移轴微距摄影，暖色自然光，浅景深，博物馆级建筑沙盘，真实纸张纹理与 PBR 材质。
```

## 重点检查

- 故宫要成为古城核心，不要被现代建筑遮挡。
- 燕山应表现为真正的浮雕地形。
- 现代地标可视觉压缩，但不要全部堆在故宫内部。

# Style Guide

## 核心视觉身份

这套风格不是“3D 城市效果图”，而是四层叠加：

1. **复古纸质地图**：暖米黄、轻微旧化、印刷道路与地名。
2. **3D 地形浮雕**：山脉、河谷、海岸、岛屿从纸面抬升。
3. **城市微缩沙盘**：地标、街区、树木、桥梁、机场、港口都以建筑模型尺度呈现。
4. **移轴微距摄影**：主体锐利、前后虚化，产生“真实微缩世界”错觉。

## 画面比例

- 默认：1:1，适合社交媒体与通用展示。
- 海报：3:4 或 4:5。
- 横版：16:9，适合展示城市带、河谷或海湾。

## 镜头

- 35–45° 斜俯视。
- 等效 50–100mm 微距/移轴观感。
- 景深浅，但城市核心必须清晰。
- 不要超广角畸变。

## 材质

### 地图纸

- 暖米黄色、亚光。
- 可见轻微纸纤维。
- 老式地图印刷色，不使用纯白背景。

### 建筑

- 真实建筑模型材质。
- 玻璃、石材、砖瓦、混凝土应有区分。
- 避免塑料玩具光泽。

### 水体

- 中低饱和蓝色。
- 允许细微高光和船迹。
- 不要做成镜面或热带荧光蓝。

## 光线

默认采用左上方柔和暖光：

- 阴影短而清晰。
- 对比度中等。
- 不做夜店式霓虹或强烈 HDR。

## 地标选择

优先级：

1. 轮廓识别度
2. 城市代表性
3. 空间分布价值
4. 历史/现代对比
5. 模型可表现性

每张图通常 3–7 个主要地标足够。地标太多会失去视觉层级。

## 地理关系

默认不是严格 GIS，但要遵守三条底线：

- 基本方位不能完全颠倒。
- 河流、海岸、岛屿、机场等大尺度关系要合理。
- 桥梁、港口、机场必须与对应地理环境真实连接。

## 文字

- 城市主标签最大。
- 其他地名小一到两级。
- 默认中英双语。
- 不超过 6–10 个主要文字标签。
- 图像模型容易生成错误文字，因此“准确文字”属于后期排版任务，而不是纯生成模型的可靠能力。

# Base Prompt

```text
生成一张极其精致的【城市名称】立体微缩地图沙盘。

底层是一张平铺在桌面上的暖米黄色复古纸质地图，具有真实纸张纤维、旧式印刷油墨、道路、河流、边界、海岸线、地名、比例尺和指南针。地图并不是纯平面展示：从【城市名称】所在区域开始，二维地图逐渐向上生长，形成高精度 3D 地形与城市微缩模型。

城市主体采用 miniature city diorama / architectural scale model 风格，清晰表现【核心地标】；结合【自然地理特征】；并根据需要加入【基础设施】。建筑、树木、道路、桥梁、水域、港口、机场、车站、船只、飞机等都保持精致微缩模型尺度与真实材质。

地图中央或主视觉区域用暗红色星标标记“【英文城市名】 【中文城市名】”。周边仅保留少量有助于定位的地名，如【周边地名】。文字采用经典老地图衬线字体、轻微油墨不均匀感，中英双语为主。

构图采用 35–45 度斜俯视角。主体城市位于中景，前景利用【前景地理元素】形成空间层次，后景延伸到【后景地理元素】。允许为视觉效果适度压缩地标间真实距离，但保持基本方位与地理关系合理。

采用 tilt-shift macro photography，极浅景深，主体区域锐利清晰，前景与远景自然虚化，产生真实微缩世界错觉。柔和暖色自然光从左上方照射，形成细腻短阴影和轻微体积感。整体像博物馆级手工地理沙盘：真实、克制、精密、高级，不是卡通或塑料玩具。

```

## 变量建议

- `【核心地标】`：3–7 个，避免塞入过多。
- `【自然地理特征】`：优先写对城市身份最关键的 2–4 个。
- `【基础设施】`：仅在需要时加入机场、港口、铁路、桥梁等。
- `【周边地名】`：3–6 个即可。
- `【前景地理元素】` 与 `【后景地理元素】` 用于建立真实层次。
